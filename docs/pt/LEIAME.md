## Instalação

### Windows

1. Baixe o [LibreScore.exe](https://github.com/LibreScore/app-librescore/releases/latest/download/LibreScore.exe)
2. Abra o arquivo EXE para instalá-lo.

### macOS

1. Baixe [LibreScore.dmg](https://github.com/LibreScore/app-librescore/releases/latest/download/LibreScore.dmg)
2. Abra o arquivo DMG
3. Mova o arquivo APP para a pasta Applications para o instalar
4. Segure o Control e clique no arquivo APP
5. Clique em `Abrir` no menu de atalhos
6. Clique em `Abrir` na parte inferior
7. Feche o arquivo DMG
8. Segure o Control e clique no arquivo DMG
9. Clique em `Ejetar` no menu de atalhos

### Linux

1. Baixe [LibreScore.AppImage](https://github.com/LibreScore/app-librescore/releases/latest/download/LibreScore.AppImage)
2. Instale `fuse2` para a sua distribuição
3. Digite o comando `chmod a+x ./LibreScore.AppImage` para fazê-lo um executável
4. Digite o comando `./LibreScore.AppImage --install` para instalá-lo

### Android

1. Baixe o [LibreScore.apk](https://github.com/LibreScore/app-librescore/releases/latest/download/LibreScore.apk)
2. Abra o arquivo APK para instalá-lo.

> Nota: Uma mensagem pode aparecer sobre o Play Protect. Clique em `Instalar assim mesmo` na parte inferior.
